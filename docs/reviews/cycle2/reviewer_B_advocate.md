## 2. The six open questions

**Q1 — Context accumulation / what the model actually sees at step t.** Fully traced. Messages payload per step: system = Ψ_total (persona core + financial extension, from `get_financial_persona`); human = date + 7 market observables (Price, SMA20/"SMA60"(=50d), trend regime, RSI14, P/E, implied vol, volume ratio, sentiment) + **portfolio status (cash $, holdings $)** + [memory arm only: "*** ACTIVE MEMORY REFRESH *** Strictly adhere to your core mandate: {M} … Evaluate this trade ONLY through the lens of this mandate."] + JSON format instructions. No message history, no MessagesPlaceholder, `reset()` is a no-op. Consequences: (i) Appendix L's dollar-quoting rationales are fully explained — no hidden state, no fabrication; (ii) Eq. 3/5's O_t and Table 2 omit the portfolio input → **documentation fix**; (iii) the *mechanism* claim (mandate loses salience as context grows) is broken as literal token-level claim — same token distance at t=200 as t=1 — and must be reframed as closed-loop behavioural drift / prompt-composition. This split verdict matters: the *measurementss* are of a real closed-loop process; only the causal story about attention over growing context is untested. The memory arm is honestly describable as "mandate present once (system) vs. twice (system + recency position)" — which is precisely the deployed pattern for stateless tool agents, and should be sold as such.

**Q2 — Newer draft?** No. `paper_current.txt` and `paper_post_rebuttal.txt` are byte-identical (diff empty; Cycle 1's own metadata says similarity 1.0000). Git shows no newer paper artifact. The Revision Plan predates the current PDF (targets 4.1×/Table 7/N=210). One Cycle-1-era complaint *is* already fixed in the current PDF: the rebuttal-round "Gemini 2.5 Flash universal benefit" mislabel — Fig 5 now labels Gemini 2.5 **Pro** universal-benefit, which the data support (+8.4/+3.8/+4.1).

**Q3 — Classifier circularity.** Confirmed from `analysis_may\persona_classifier.py`: training pool = days 1–5 rationales from **both arms** (no Agent_Type filter, lines 117–125), balanced ≤2000/class, 85/15 random stratified split *within the same pool* (n_train 2,372 / val 418, val acc 93.5%, `outputs\persona_classifier\metrics.json`). So "93–95% held-out accuracy" is within-distribution; memory-arm rationales that echo mandate vocabulary verbatim ("As a Momentum Commander…") are in training, making P(intended persona) partly a mandate-echo detector — the near-ceiling memory-arm scores (≥0.98) are close to tautological. Defences: (a) none of the headline behavioural results (MAS/CI/RG, Tables 1/9/11) touch the classifier; (b) for the placebo *sanity check* the circularity is harmless — the question asked is exactly "does the placebo text activate mandate-associated language?"; (c) `make_hero_figure.py` already excludes training days from plots. Cost of a clean fix: retrain excluding memory arm + hold out models/arms — hours of GPU, zero API spend. CONCEDED as a validity limit on App H's linguistic recommendations and the open-weight Cliff's-δ=1.0 claims; cheap to repair.

**Q4 — t=0 persona separability.** Computed (static arm): day-1 post-action cash ENTJ 0.882, INTJ 0.922, ISFJ 0.919; ANOVA F=0.9, p=0.395, η²=0.007; day-1 BUY rates 0.29/0.19/0.26. **Personas are not behaviourally separable on day 1.** Separation emerges cumulatively (flat static run-mean cash 0.296/0.278/0.493) — and note ENTJ vs INTJ realised cash is *inverted* relative to targets (0.296 vs 0.278 against C_ideal 0.2 vs 0.5). This is a genuine adverse finding for the persona axis: the instrument induces one strong contrast (ISFJ vs rest) and a weak/ambiguous ENTJ–INTJ contrast. It does **not** kill the sign-reversal result (which needs only the ISFJ/ENTJ endpoints to respond oppositely — they do), but Ross-&-Lo-style heuristic collapse cannot be ruled out for the middle of the scale. Report it; add the t=0 baseline as C recommended.

**Q5 — Crash at model level under any defensible spec.** Answered in §1.1 #7: pooled — no (best p = 0.112 across sign test, model-level Wilcoxon, t-test, MixedLM with Model + seed random effects; point estimate +3.1 pp, CI [−0.7, +7.0]). Persona-conditional — **yes**: ISFJ 14/18, +7.47 pp, Wilcoxon p = 0.0038, sign p = 0.031 (survives even Bonferroni×3 at 0.0114). Caveat to report alongside: 125/264 ISFJ-memory crash runs execute zero trades (MDD exactly 0 vs −15.4% for the trading ISFJ-memory runs), so the mechanism is "re-grounding keeps the guardian out of the market", not "prevents panic-selling of held positions". That is mandate-compliant behaviour, but the "panic-selling failure mode" language must go; "capital-preservation adherence under stress" is the supported claim. Also: pooled crash MDD survives Holm within Table 9's family (adj-p 0.0107) — the model-level unit-of-analysis critique, not multiplicity, is what bites.

**Q6 — If it is generic instruction salience, is it still publishable?** The best case: (i) the *placebo* already rules out the purest position-only story at n=1 model (placebo tracks static within 0.003–0.047 while memory moves 0.11–0.17 in opposite persona-specific directions; static-vs-placebo p=0.041 shows position alone has a small uniform *negative* effect — the opposite sign of the memory effect for ISFJ); (ii) even if the swapped-mandate arm showed effects don't track content, the residual finding — "any imperative re-injection at the recency position shifts behaviour with a sign determined by the metric's target, at 18-model × 3-regime × 200-step scale, with a ground-truthed scoring function" — is a useful negative/measurement result about re-grounding as deployed practice, publishable at a solid workshop or findings-track venue (COLM/ICLR workshop, ACL Findings tier); with the swapped-mandate arm *confirming* content-tracking it is a main-track behavioural-evaluation paper. The 18-model scale, paired 200/800-step design, and the bidirectional regime×mandate map remain above the corpus median on coverage regardless of which way the attribution lands.

## 3. Defence of the surviving contribution (content-isolated sign reversal)

**Counts verified from raw data**: flat market, memory-vs-static MAS per model: ISFJ improves in **17/18** (exception Gemma-3-4B), ENTJ degrades in **16/18** (exceptions Llama-3.1-8B, Gemma-3-4B), INTJ mixed 11/18 — exactly as Figure 4's flat column and §4.3.3 state, including "five models with ISFJ-memory MAS = 0.000" (deepseek-chat, gemma-2-9b, gpt-4.1, gpt-4o, gpt-4o-mini) and "deterioration up to 156.4%" (gpt-5.4). Model-level interaction (ENTJ Δ vs ISFJ Δ): Wilcoxon **p = 3.8e-5**. Per-persona paired effect sizes: ENTJ dz = +1.05, ISFJ dz = −1.12 (n=90 pairs each) — textbook-large; the pooled dz of −0.22 that Cycle 1 quotes is small only because opposite-signed effects cancel.

**Against the tautology objection.** Read the actual texts (agent\personas\mbti_profiles.json; agent\ocean_prompts.py:192–224):
- ENTJ mandate: "…Be decisive. If the trend is up, BUY. If the trend breaks, SELL. Do not hesitate… CHASE THE BIG WINS." — note it contains *no allocation target*; C_ideal=0.2 is the experimenters' scoring stipulation.
- O3-aggressive mandate: "REMINDER: Your target cash allocation is 20%. Adhere to this target."
- The O3 result (verified from `results_ocean` raw: memory−static = **−0.028 / −0.038 / −0.093** for Sonnet / Flash / 4o-mini — memory *helps* in all three models) shows that re-injecting an instruction *that encodes the target* improves adherence even for the aggressive profile. So the ENTJ harm is not "any instruction at the recency position gets penalised"; it is specifically the action-inciting trait language, which pushes behaviour away from the target the language never mentions. That is a semantics effect — but the honest form is: **the effect of re-injection is determined by the relation between the injected content and the scored target**, not "mandates decay and re-grounding restores them". For ENTJ, mandate text and scoring target were never aligned; re-injection faithfully amplifies the text, and the metric (correctly) reports the divergence.
- Non-MAS behavioural signatures point the same way but are only directional: ENTJ memory trades **more** (+17.9 trades, 12/18 models; BUY share +7.9 pp) while ISFJ memory trades less (−3.7; BUY share −2.3 pp, model-level p=0.027). A generic caution shift cannot produce more churn in one persona and less in the other. However, mean cash rises in *both* personas (+0.096 ENTJ, +0.259 ISFJ; magnitude interaction p=0.0028), so a same-signed, different-magnitude cash shift refracted through opposite targets is **not fully excluded** — Reviewer B's objection survives in weakened form. The trade-count interaction is directionally against it but n.s. at model level (p=0.18). Verdict: the *metric-level* reversal is unimpeachable; the *behavioural bidirectionality* is probable but unproven; the swapped-mandate arm (15–90 sims) settles it and is the single highest-value experiment available.

**Cash-mediation regression (run as instructed).** Pooled flat MAS: arm coef −0.0495 (cluster-robust by model, p=0.0001) → −0.0059 (p=0.67) controlling mean cash — but this is close to controlling for the outcome (for ISFJ, MAS ≡ 1−cash identically; the regression is structural, coefficient forced to 0). The informative cells: **ENTJ arm effect survives controlling cash (+0.0739, p≈5e-12)** — memory harms ENTJ adherence beyond any cash shift (via churn/side-of-target effects); **bull-trap RG arm effect survives controlling cash (−8.33, p=0.0001)** — the rationality cost is not a pure allocation artifact; **crash MDD arm effect reverses sign controlling cash (+3.29→−2.88)** — the crash benefit is entirely cash-mediated (which is fine: holding cash *is* the mandate; but it kills "prevents panic-selling" as mechanism). Within-scenario metric correlations: |r(MAS,RG)| = 0.04–0.39, |r(MAS,MDD)| = 0.34–0.45, r(cash,MDD) = 0.67–0.89 — "three metrics, one variable" is true only for the cash–MDD pair; report the matrix, keep MAS and RG as partially independent axes.

**Prior art (PDFs read).** ContextEcho (2605.24279): filler-control arm (anticipates the placebo — concede C11) and an anchor-*content* ablation (V0 identity-sentence vs V2 format-demo vs 200-token) — content variation exists there, but for register/persona drift with judge scoring, no behavioural task, no ground truth, and no content×regime sign reversal. Meta 2607.08716: varies *intervention policy* (selective vs always-on; "unnecessary interventions can be harmful") — anticipates the broad "re-grounding not universally beneficial" (concede C10 broad form) but never varies the semantic content of a standing mandate. CLQT 2606.29771 §3.5: ships a Ct<0.7 drift-warning injection inside a mandate-aware financial benchmark — anticipates the *adaptive controller* future-work item, never ablates content, names mandate variation as future work. Kim/Li COLM 2024: System-Prompt-Repetition swept over injection probability p with a capability-cost axis — **App H's frequency ablation is fully anticipated (concede C13)**; no content variation. Conclusion, agreeing with Cycle 1's own Part VII: the narrow claim — *fixed environment, position, cadence, model; varying only injected mandate content reverses the sign of the intervention's behavioural effect (17/18 improve under capital-preservation, 16/18 degrade under growth, interaction p=3.8e-5 at model level)* — is unclaimed in the corpus. That is the paper.

**Strongest defensible form for the revision**: "In a fixed 200-step financial decision environment, the behavioural effect of re-injecting a standing mandate at the recency position is determined by the mandate's content: capital-preservation content moves 17/18 models toward preservation (dz ≈ 1.1), growth/action content moves 16/18 models away from their allocation target (dz ≈ 1.1), and a length- and position-matched declarative placebo moves nothing (|Δ| ≤ 0.047, one model). A numerical-target-only mandate eliminates the harm in all three models tested. Content attribution beyond this is tested by the swapped-mandate arm [new]." Plus S2 restated: longest paired ground-truthed instrument (200/800 steps, 18 models), with "ground truth" restated as generator-defined, observable-inferable value.
