Take-aways that the literature below should fix:
1. No fat tails, no volatility clustering in `flat` (kurtosis ≈ 0, ACF\|r\| ≈ 0) — the "GARCH-like" recursion (0.7ϕ+0.3\|ε\|) only scales an additive dollar noise of 0.5 $, i.e. ≈0.5 % of price; the dominant variation is the GBM value path with constant σ.
2. Crash returns have ACF(1) ≈ −0.45: additive i.i.d. dollar noise around a slowly moving level produces MA(1)-type negative autocorrelation (bid-ask-bounce signature) — a detectable artefact and a free mean-reversion signal for any agent.
3. δ ∈ {0.85, 0.92, 0.95} changes max drawdown by ≤ 0.6 pp (−47.5 vs −47.0 %); the drawdown is set by the deterministic −12 $ decline plus the N(−0.5, 1.0)·60-day panic random walk in value (V falls ≈ −42 % on average), not by δ. Mispricing in crash is i.i.d. (ACF ≈ 0), i.e. not persistent.
4. Bull-trap mispricing is additive dollars (cumsum of N(1.5, 0.5) $/day) so P/V reaches 2.2 with almost no volatility (daily σ 1.3 % < flat), and volume is *negatively* correlated with \|r\|.
5. IV is a deterministic function of phase in crash/bull (identical across seeds) → leaks the phase clock.
6. P/E = 15·P/V reveals V exactly; dividend yield = 0.4/15 · V/P ·100 reveals V again.
